# Anotações sobre Azure Language Studio

## Primeiras impressões
- Ferramenta voltada para análise de linguagem natural em textos.
- Interface clara, com opções de testes rápidos e criação de projetos.

  [![Language Studio](https://github.com/robsonosbor/lab-azure-language-studio-ai/blob/main/images/studio-language.png)](/)

## Experimentos simulados
- **Análise de sentimentos**: frases positivas e negativas foram classificadas corretamente.

- **Extração de entidades**: identificação de nomes, locais e datas em textos simples.

- **Classificação de intenções**: diferenciação entre frases como “Quero comprar um produto” e “Preciso de suporte técnico”.

## Desafios iniciais
Compreender como estruturar datasets para treinar modelos mais robustos. Como iniciante, ainda estou aprendendo a preparar dados de forma organizada.

## Insights
- Language Studio é essencial para chatbots, análise de feedback de clientes e sistemas de suporte.
- A combinação com Speech Studio permite criar soluções completas de voz e texto.
- Documentar cada teste é fundamental para acompanhar a evolução dos modelos.
